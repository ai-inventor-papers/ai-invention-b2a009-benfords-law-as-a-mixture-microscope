## Full Summary

Two country-year total-population panels, each in the pipeline's exp_sel_data_out layout with ONE EXAMPLE PER ENTITY-YEAR, grouped by dataset. (1) country_population_panel_1950_2023: 18,012 examples over 237 entities, 1950-2025, sourced from the UN World Population Prospects 2024 via the Our World in Data grapher 'population-with-un-projections' (taking the estimates column through 2023 and the medium-variant projection column from 2024; estimates 1950-2023 form the primary analysis window, 2024-2025 are flagged is_projection=true). (2) worldbank_wdi_sp_pop_totl: 14,292 examples over 217 entities, 1960-2025, from the World Bank WDI bulk archive for indicator SP.POP.TOTL (1960-2023 primary). The second panel is a genuinely independent source, not the same numbers twice, so it supports a source-invariance comparison rather than duplicating the first. Each example carries input ('<ISO3 or slug>|<YEAR>'), output (the published value verbatim as a string, preserving significant-figure grain), and FLAT metadata_* fields: entity, iso_code, entity_class (sovereign/territory/other), year, population, value_str, source_variant, source_release, is_projection, in_primary_analysis, in_primary_analysis_sovereign_only, pop_le_1m, is_sids, sids_source, is_top20, rank_in_year, mantissa (fractional part of log10, 0<=m<1), d1, d2, d1_reciprocal (the reciprocal/mirror control), n_sig_figs, trailing_zeros, entity_year_rank_source, notes. metadata_fold is the pre-registered even/odd calendar-year split: 'even' is the screen half (8,769 primary-window observations), 'odd' is reserved for confirmation. Aggregates (World, continents, income groups, EU, OECD, OWID_/UN_ group codes) are excluded by an explicit auditable rule; dependent territories are kept and tagged so the microstate/SIDS/top-20 ablations can run. Integrity is gated: zero duplicate (iso_code, year) and (entity, year) keys, population positive integers matching value_str, mantissa in [0,1), string-derived d1 agreement 0.9999 with one listed exact-decade boundary case, reciprocal control agreement 1.0000, and the 2023 sum over in_primary_analysis entities equal to 8,090,655,899 persons (+1.13% of the ~8.0e9 world total, which catches the persons-vs-thousands error). No derived digit statistics are stored: no digit frequency table, MAD, chi-square, Kuiper statistic, fitted size law or bootstrap is present on any row, because those belong to the experiment stage. Verification: all nine published JSON files validate against the vendored exp_sel_data_out schema (the aii-json skill's own validator reports 'Validation PASSED'), and build/verify_outputs.py runs five PASS/FAIL check groups (schema, qc, acceptance, sanity, audit) exiting non-zero on any failure. Data is fully deterministic: no seeds, no sampling, no model, and data.py reproduces full_data_out.json byte for byte at md5 a338376ff319aa913078df4669fde237. mini_data_out.json and preview_data_out.json are byte-identical to the aii-json formatter's own output for the same input. full_data_out.json is 43 MiB, under the 100 MB per-file limit, so it is not split.
